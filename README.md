# Capstone-Final-Project-PJ
Project Name: Phoenix Jensen Capstone Final Project
My project answers the question of how to adjust inventory to avoid back orders. When items go out of stock this creates a major inconvience for the consumer and the company attempting to sell the product. This project creates a model that will include the changes in inventory and demand overtime to predict future variation in demand. This added information can be used by stockholders to adjust thier inventory levels to meet consumer demand and prevent the number of backordered items. 
Data Source: https://www.kaggle.com/datasets/raminhuseyn/demand-forecasting-dataset/data
Instructions for setting up the enviroment (pip install -r requirement.txt)
